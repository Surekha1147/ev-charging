📌 Description

The EV Charging Station Finder is a modern, responsive front-end web application that helps users explore nearby electric vehicle charging stations. This project uses static data to simulate real-world charging stations, making it ideal for UI/UX demonstration and frontend development practice.

🚀 Features
🔍 Search and browse EV charging stations
📍 Display stations using mock (fake) location data
⚡ Filter by charger type (Fast / Normal)
💰 View simulated pricing and availability
🗺️ Map-style UI layout (visual representation)
❤️ Wishlist page UI
🛒 Cart/booking interface UI
📱 Fully responsive and attractive design
🛠️ Tech Stack
HTML5 – Structure
CSS3 – Styling & animations
JavaScript (Vanilla JS) – Interactivity
Bootstrap – Responsive design

⚙️ How to Run

Download or clone the repository

git clone https://github.com/your-username/ev-charging-finder.git
Open the project folder in VS Code
Run index.html in any browser
⚠️ Note
This project is frontend-only
All EV station data is mock/fake data (no real-time API or backend connected)
Designed purely for UI/UX demonstration and learning purposes
